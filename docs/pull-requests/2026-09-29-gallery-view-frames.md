# PR：去掉画廊视图的嵌套边框，画面按窗口大小自适应排布

- **日期：** 2026-09-29
- **分支：** `fix/gallery-view-frames` → `main`
- **基线提交：** `472aaba`
- **关联记录：** [工作记录](../work-logs/2026-09-29-gallery-view-frames.md)

## 关联

作者反馈会议界面的画廊视图边框太多，破坏了界面的一致性。从作者的截图看有这些问题：

- **边框套了三层：** 窗口边框 → 画廊容器的圆角边框 → 卡片边框，卡片里的缩略图还有一层边框。占位背景是直角的。
- **只有一个人时，画面下半截被裁掉**，名字标签也看不到了。
- **两套名字标签叠在一起。**
- **头像字母显示成 "X("**，因为首字母是从「名字 (You)」里取的。

## 改了什么

- **只剩一层：** 画廊不再有容器边框，每个画面是一个没有边框的圆角块，直接放在窗口上。视频本身也裁成圆角。
- **自适应排布：**
  - 对每种列数计算 16:9 画面能有多大，取最大的一种；
  - 整体居中，最后一行也居中；
  - 画面太小（宽度低于 220px）时才改成纵向滚动。
- **标签：**
  - 每个画面只保留一个名字标签（半透明深色底，带麦克风状态）；
  - 高亮只有一圈 2px 主题色；
  - 会中只有一个人时不显示高亮。
- **没有视频时：** 显示按名字取色的圆形头像。首字母会先去掉 " (You)" 这类后缀。
- **修复镜像：** 只共享屏幕、不开摄像头时，自己的共享画面原来会被左右翻转。
- **代码整理：**
  - 本地、远端两份几乎相同的卡片代码合并成 `GalleryTile.qml`；
  - 画廊布局和帧分发移到 `GalleryView.qml`；
  - `ConferenceWindow.qml` 净减约 400 行。
- **演讲者视图：** 左侧列表的缩略图同样使用 `VideoThumbnail`，因此也去掉了边框并变成圆角。除此之外，演讲者视图没有改动。
