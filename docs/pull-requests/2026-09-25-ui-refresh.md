# PR：界面整体翻新：腾讯会议风格配色、紧凑首页、设置页重做、Lucide 图标

- **日期：** 2026-09-25
- **分支：** `feat/ui-refresh` → `main`
- **基线提交：** `d2f0a9c`
- **关联记录：** [工作记录](../work-logs/2026-09-25-ui-refresh.md)

## 关联

原有界面存在以下问题：

- **配色**：只有黑白灰，大量颜色直接写死在各个 QML 里，深色主题下有多处看不清。
- **首页**：1160×720，四张大卡片加空旷的列表，显得松散。
- **设置页**：只是简单罗列控件。
- **图标**：34 张 PNG 是手动收集的，风格不统一，而且因为是黑色位图，只能靠 `opacity` 调深浅，无法和文字颜色一致。

本 PR 的目标是参照腾讯会议，把界面改得更紧凑、简洁、精致，并统一配色和图标。

## 改了什么

### 图标：全部换成 Lucide

- 删除 `res/icon/*.png` 共 34 张；应用图标 `res/icon/appIcon/**` 保留。
- 新增 `res/icon/lucide/` 共 43 个 SVG，来源为 allsvgicons.com，附 Lucide 的 ISC 许可证。
- 下载后做了两处处理：
  - `currentColor` 改为白色，这样经 `MultiEffect` 着色后正好等于目标色（已对照 Qt 的 `multieffect.frag` 确认）。
  - 尺寸由 `1em` 改为 `24`，因为 Qt SVG 不支持 `em`。
- 新增 `Icon.qml`（`name` / `size` / `color`），所有图标统一经它渲染，颜色跟随主题。
- CMake 增加 `Svg` 组件并链接 `Qt6::Svg`，确保 windeployqt / macdeployqt 打包时带上 `qsvg` 插件。

### 配色

- `Theme.qml` 改为腾讯会议式品牌蓝 `#1F6FFF`，配冷色调浅灰底和 slate 系文字。
- 新增语义色 token：`success`、`danger`、`warning`、`icon*`，以及圆角尺寸。
- 浅色、深色两套都已重新定义。
- 旧的属性名全部保留，未改动的 QML 不受影响。
- 登录、弹窗、会议、共享选择器里写死的颜色都改为引用 token，修正了深色主题下看不清的问题。

### 首页（880×580）

- 左侧 64px 图标导轨：
  - 顶部是头像：显示用户名首字母；点击弹出账号菜单，游客则弹出「登录 / 注册」。
  - 中部为导航，选中项左侧有指示条。
  - 底部是设置入口。
- 中间 2×2 蓝色图标块：加入会议、快速会议、预定会议、共享屏幕。游客点快速会议和预定会议时，图标块带锁角标，点击后仍走原有的登录提示。
- 右侧大号日期加星期，下方为「会议记录 / 我的预定」分段切换和扁平列表：
  - 每行显示「时间 · 会议号」。
  - 状态胶囊按状态着色。
  - 空状态带图标。
- 操作弹窗和登录弹窗改为挂在 `Overlay.overlay` 上，并按窗口高度收缩，保证在小窗口里放得下。

### 设置页（680×500）

- 左侧图标导航；右侧页头显示标题和一句描述，关闭按钮在右上角。
- 设置项改为「分组卡片 + 行」：左边是说明，右边是控件；复选框改为开关，自绘的分段按钮换成 `SegmentedPicker`，滑条统一样式。
- 所有 `backend.*` 读写逻辑一字未改。

### 会议窗口与共享选择器：只换图标和配色，布局不变

- 麦克风、摄像头关闭时显示为红色。启用了 `ParticipantItem` 里原本被注释掉的着色逻辑。
- 挂断、结束共享改为红底白图标。
- 视频浮层上的图标统一为白色。
- 底栏高度由 68 调整为 60。

### 新增与删除的文件

- **新增的公共组件**：`ToggleSwitch`、`BrandSlider`、`StatusPill`、`SettingsSection`、`SettingsRow`、`SegmentedPicker`。
- **删除的死代码**：`HomeContactsPage.qml`、`InviteOptionCard.qml`。两者都未登记到 CMake，且仍引用旧 PNG。

### 首次运行后修复的问题

| 现象 | 原因 | 修复 |
| --- | --- | --- |
| 启动报 `"implicitHeight" is a read-only property` | `Image` 的隐式尺寸由图片源决定，不可赋值 | `Icon` 根元素改为 `Item`，内部放一个 `Image` |
| 首页操作块被挤到导轨边缘 | 嵌套在布局中的子布局 `Layout.fillWidth` 默认为 `true`，右侧栏和操作区争抢宽度 | 右侧栏显式设置 `fillWidth: false`，宽度固定为 300 |
| 设置页关闭按钮紧跟在标题后面 | 列里只有不填充的 `Text`，布局的最大宽度由子项决定，所以列伸展不开 | 两个 `Text` 设置 `fillWidth` |
| hover 移出时背景闪一下 | 背景颜色动画的终点是 `"transparent"`（`#00000000`，透明黑），插值过程中会出现半透明深色帧 | 新增 `Theme.clearOf()` / `hoverClear`，动画过程只改变透明度 |
