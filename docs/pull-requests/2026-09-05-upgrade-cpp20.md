## 关联

解决项目以 C++17 编译 C++/WinRT 时，新版 MSVC 14.51 因拒绝 `<experimental/coroutine>` 而产生的 `STL1011` 构建错误，同时消除未明确设置 QTP0004 产生的 Qt 开发警告。

## 改了什么

- 将项目的 CMake C++ 标准从 C++17 升级为 C++20，使 C++/WinRT 使用标准 `<coroutine>`。
- 调用 `qt_standard_project_setup(REQUIRES 6.8)`，统一启用 Qt 6.8 及以前的现代 CMake 策略，并移除重复的 `GNUInstallDirs`、`AUTOMOC` 和 `AUTOUIC` 手工设置。
- 将 README 和仓库开发指南中的编译器要求同步为 C++20。
- 增加本次工作的工作记录和 PR 记录。
